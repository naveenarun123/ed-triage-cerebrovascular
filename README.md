# ED Triage Disposition Checklist for Incidental Cerebrovascular Findings

A browser-based clinical decision aid operationalizing the BIDMC ED–Neurosurgery triage protocol for incidental intracranial aneurysm / cerebrovascular findings.

- Runs entirely in the browser — no server, no data transmitted or stored.
- Collects only clinical parameters; no patient identifiers.
- Decision support only; not a substitute for clinical judgment.
